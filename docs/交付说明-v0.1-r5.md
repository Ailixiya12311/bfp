# BFP v0.1-r5 交付与运行说明

状态：r5 是已保留的阶段候选，WAN 严格 UDP 门槛未通过，未发布正式 ZIP。本文保留该候选的运行合同；下一修订将补充独立证据，不覆写 r5 失败。

本修订提供直接运行于 UDP/TCP 的独立 Go 实验协议。默认 UDP，失败后接到同一服务端 TCP，保留仍存活的 Session 和出口连接；业务可以短暂停顿。新增会话凭证生命周期与类别分层调度，正式稳定 wire 和生产安全结论尚未冻结。

## 文件入口

- `bin/bfp-v0.1-r5.exe`：Windows amd64 客户端、服务端和实验 CLI。
- `bin/bfp-v0.1-r5-linux-amd64`：同源 Linux amd64 构建。
- `docs/验收记录-v0.1-r5.md`：本轮构建、本地与远端证据。
- `docs/会话凭证生命周期.md`：Ticket 有效期、逻辑刷新、设备撤销、最大会话截止和配置。
- `docs/需求验收清单-v0.1-r5.md`：完整设计逐项差异与连续开发顺序。
- `docs/接入方案与版本边界.md`：Mihomo/sing-box 固定源码基线及尚未开发的原生接口。
- `verification/v0.1-r5/validation.json`：本地检查及两平台实际摘要；`release-evidence.json` 另关联本轮远端证据。

双机实验为新加坡 `198.51.100.20` 发送、洛杉矶 `192.0.2.10` 接收/出口。实验进程与凭据使用 owned 临时目录，结束精确清理；交付不是两机常驻安装。包不含设备秘密、SSH 凭据、服务器清单或 known_hosts。

## Windows 运行

项目根目录 PowerShell，凭据目录须尚不存在：

```powershell
.\bin\bfp-v0.1-r5.exe keygen -out .\credentials-local
```

终端一启动默认本机双承载服务，终端二启动客户端与 loopback SOCKS5：

```powershell
# 终端一
.\bin\bfp-v0.1-r5.exe server -config .\credentials-local\server.json -stats 1s

# 终端二
.\bin\bfp-v0.1-r5.exe client -config .\credentials-local\client.json
```

默认地址为服务 `127.0.0.1:51880` 和 SOCKS `127.0.0.1:1080`。默认网关拒绝私网、loopback 和特殊地址；本机 echo 实验需明确限定授权目标 CIDR 与端口。SOCKS 支持 CONNECT/UDP ASSOCIATE，非零 FRAG 丢弃；具体 Mihomo/sing-box 版本的 SOCKS/TUN/fake-IP/IPv6 支持矩阵仍待真实软件验收。当前没有 native BFP outbound。

## 生命周期配置

keygen 保留兼容配置，不自动写 options。server/client/probe 可在 JSON 顶层增加：

```json
{
  "options": {
    "ticket_ttl": "20m",
    "ticket_refresh_lead": "5m",
    "ticket_overlap": "30s",
    "max_session_lifetime": "24h"
  }
}
```

字段省略使用核心默认；以上数值即默认值。字符串必须为正的 Go duration，TTL/最大寿命限制 40 ms 至 720 h，提前量至少 1 ms 且小于 TTL，overlap 至少 1 ms 且不大于 TTL。错误只标字段及规则，不回显配置值。完整配置仍必须包含各角色地址、credentials 与出口 policy；上面是 options 片段，不是可单独启动的配置文件。

Ticket 到期禁止恢复，不自动关闭健康业务。活动承载在截止前刷新，客户端安装后发逻辑确认；最大 Session 寿命则固定关闭。撤销设备目前通过服务端 Go API `RevokeDevice(publicKey)`，不是 CLI 热管理命令。它不轮换部署准入秘密或 Session 的恢复 PSK。

必须让两个端点使用同一 r5 构建；新增必需握手字段和帧与 r3 没有跨修订能力协商。密钥文件沿用 Windows owner-only DACL 与 Unix 私有 owner/mode 校验；编辑后须保持权限，不能输出到共享日志。SOCKS 保持本机入口。

## 验证与重建

本地当前 Go 1.27，模块要求 Go 1.26.0。源码变化后创建新的命名修订与证据，不能沿用 r5 的摘要：

```powershell
go test ./... -count=1 -timeout=45s
go vet ./...
go mod verify
go build -trimpath -o .\bin\bfp-local.exe ./cmd/bfp
```

本轮本地 11 包、140 个顶层测试、247 个含子测试通过事件，Windows 一项 symlink 权限 skip。Ticket 逻辑刷新/丢 ACK、恢复保留目标、候选撤销与寿命尾部有独立回归；冻结源码 Linux race 与新构建 WAN 见验收记录。内部测试不构成独立安全审计、所有网络环境可用或长期不可识别的证明。

类别外层总字节权重 4:2:1 已进入 Session 路径；纯滑动窗口分类器尚未接入，当前仍有累计字节阈值。ACK ranges/PTO、原生接入、控制独立预算、全局资源与性能矩阵仍需开发。FEC、SHAPED/COVER 和 TCP→UDP 自动回切作为后续扩展记录。r4 的调度器准备失败与早期 r2 WAN 49/50 失败都保留原始证据。
