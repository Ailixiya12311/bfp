## 2. Windows 本地运行

项目根目录 PowerShell。输出凭据目录必须尚不存在，程序不覆盖已有目录/文件：

```powershell
.\bin\bfp-v0.1-r6.exe keygen -out .\credentials-local
```

终端一默认同时监听本机 UDP/TCP；终端二连接并提供 loopback SOCKS5：

```powershell
# 终端一
.\bin\bfp-v0.1-r6.exe server -config .\credentials-local\server.json -stats 1s

# 终端二
.\bin\bfp-v0.1-r6.exe client -config .\credentials-local\client.json
```

默认服务地址 `127.0.0.1:51880`，SOCKS 地址 `127.0.0.1:1080`。默认出口拒绝私网、loopback 和特殊地址；本地 fixture 实验需显式 AllowPrivate，并将 CIDR/端口限制到目标。SOCKS 支持 CONNECT/UDP ASSOCIATE，FRAG 非零丢弃；真实 Mihomo/sing-box SOCKS/TUN 支持矩阵及 native outbound 尚未验收/实现。

默认配置为本地实验。双机运行需要明确服务器监听、同一出口的 UDP/TCP 地址和出口策略；远端实验临时服务不是常驻部署。TUN 必须排除 BFP carrier 端点及相关控制流，完整接入行为仍待真实软件验证。

## 3. 生命周期配置

`keygen` 生成的完整配置沿用默认值。server/client/probe JSON 顶层可增加可省略的 `options`：

```json
{
  "options": {
    "ticket_ttl": "20m",
    "ticket_refresh_lead": "5m",
    "ticket_overlap": "30s",
    "max_session_lifetime": "24h"
  }
}
```

这是 options 片段，完整启动配置仍需地址、credentials 和适用的出口 policy。字段省略使用默认；已给字段必须是正的 Go duration 字符串，TTL/最大寿命为 40ms–720h，提前量至少 1ms 且小于 TTL，overlap 至少 1ms 且不大于 TTL。未知字段、null、数值、空字符串和非法值不会静默选择默认；错误标字段和规则，不回显配置值。其他 `session.Options` 尚未全部开放为 CLI JSON。

Ticket 到期禁止用该 locator 恢复，健康活动会话可以刷新；最大 Session 寿命从首次 INIT 固定，到期关闭。下次 `Connect` 可创建新网络，旧流不会迁入新 Session。服务端 `RevokeDevice` 是 Go 进程内 API，未提供远端管理 CLI；locator 刷新不轮换准入秘密或恢复 PSK，也不是泄露后的安全恢复。

配置包含私钥和秘密；Windows 使用当前用户 owner 和受保护 DACL，Unix 使用私有 owner/mode 校验。导入配置拒绝链接、不安全权限、超限及未知/尾随 JSON。编辑后保持权限，使用可信目录。无认证 SOCKS 保持 loopback。交付运行说明不包含可使用的设备秘密或 SSH 凭据。

## 4. Probe 与重新构建

fixture、策略限定、黑洞 relay 的完整用法见[实现进度](实现进度.md)。r6 probe 在同一固定 UDP flow 上只发送一次当前消息，在原绝对截止内读到无关回包会丢弃并统计；不重发、不取消首次超时、不把后续成功回填旧请求。

新增 progress 遥测包含 `error_kind`、`timeout`、无关/迟到/异常计数及规范迭代编号，不输出原始回包。`mismatch` 与 `timeout=true` 可同时出现，表示读到过无关回包且当前请求最终到期。所有 UDP 请求成功且失败数为零才满足严格实验门禁。

源码改动后必须建立新的修订与证据，不沿用本稿摘要：

```powershell
go test ./... -count=1 -timeout=45s
go vet ./...
go mod verify
go build -trimpath -o .\bin\bfp-local.exe ./cmd/bfp
```

模块 Go 1.26.0，当前验证工具 Go 1.27.0。Windows 本地 CGO disabled，不能由这些命令推导 race 已执行；本稿关联独立 Linux 冻结源码回归。
